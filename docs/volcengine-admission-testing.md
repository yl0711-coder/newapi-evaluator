# 火山新 Key 一次性验收测试清单

适用正式规则 `docs/ai-rules` v1.0。功能属于工作台独立模块 `features/volcengine_admission`；原 `image_quality` 固定型号与报告边界保持其专项合同，实验室引擎不改动。

统一运行 `python -B scripts/verify_integrity.py --output <新外置目录>`，包含原有工作台全部组及火山两组。开发 29 组、3000 秒；独立验收在干净 detached 提交上追加 `--sha <40位SHA>`，共 30 组、4200 秒。独立环境和新证据目录按 [完整性清单](integrity-testing.md) 准备。默认 Mock，不能加载业务 Key、调用真实方舟接口或发送外部通知。

| suite_id | 入口 | 验证范围 / 时限 |
| --- | --- | --- |
| volcengine-admission-inspect | `scripts/inspect_volcengine_admission.py` | 11 个精确型号、6 个默认选择、规格、刊例价合同指纹、一次请求及查询恢复边界；不初始化、不读凭据、不联网，60 秒 |
| workbench-python | `scripts/test_all.py --output` | 必须收集 `tests.test_volcengine_admission`，验证规格/预算、确认及幂等、图片单张、视频异步终态、错误/未知提交、停止/重启补 Key 只查询、同目录进程互斥、发送前容量预留、终态样片清理、媒体校验及敏感数据边界；900 秒 |
| volcengine-admission-browser | `scripts/volcengine_admission_ui.cjs` | 隔离回环服务、默认与补充型号、预览失效、确认、鉴权、真实适配器的合成响应、样片/报告下载、停止收尾与只读恢复、切换历史时迟到响应隔离、本地样片清理确认；390/900/1440 布局，300 秒 |
| build-container | `scripts/image_quality_container.py --output` | 实际候选镜像 all 模式挂载页面/元数据、默认无执行及自有资源清理，900 秒；原生图及完整性容器回归保留 |

目录、日志、依赖和截图放在仓库外的统一测试数据目录；浏览器仅连接自有回环服务，HTTP 传输替身保留真实请求构造、解析、任务存储与报告链路。合成夹具位于 `tests/fixtures/` 与 `tests/test_volcengine_admission.py`，不复制真实提示词、响应、图片、视频或凭据。

媒体下载与任务生成分开判断；HTTP 成功、返回 task ID、上游状态成功、已取得可查看样片分别验证。临时 Key、签名媒体 URL、提示词及上游自由文本不进入持久报告、日志或开发证据；错误只输出固定分类。每项生成至多提交一次，断线后的未知提交不重发；重启补原 Key 仅查询已知视频任务，未发送项保留原状态。停止不宣称上游已取消。

容量不足必须在生成许可之前拒绝发送，不能先生成再以已满空间解释样片丢失。本地清理仅删除用户确认的终态报告样片，保留报告指标、幂等标识与视频任务 ID，不调用上游删除；活跃和正在收尾的任务拒绝清理。验证清理前后生成请求计数不变、容量释放及历史可读。视频严格结构校验不能替代实际解码或人工完整观看；浏览器可播放断言使用独立合成素材。

Mock 证明所列契约，不证明真实 Key 权限、供应商身份、实际画质、真实账单或存量型号仍可申请。官方价格快照与文档对应日期由模块目录维护；估算不作为供应商扣费上限。
