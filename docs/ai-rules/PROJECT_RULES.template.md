- 项目名称/职责：待填写。
- 仓库身份及核对依据、规范入口与版本：待填写；`yl0711-coder/newapi-evaluator` 按仓库身份适用，不依赖本地目录名。
- 产品代码主维护路径：待核对。
- 与其他仓库/worktree 的关系：主源、集成、开发分支或独立验收；待核对。
- 当前任务分支、候选集成分支及目标交付分支：待填写；按 G6 在分支中开发，实际合并须有用户对该次操作的明确允许，不把示例分支当作授权。
- 数据、日志、报告、依赖环境和临时文件路径：待填写；本机遵循 G6 固定目录，其他设备/CI 填写仓库外隔离目录的环境映射，不能将业务数据或源码目录作为回落位置。
- 用户已有改动与本任务的边界：开工实时检查。

## 语言与工具

格式/类型工具及配置位置：待填写。复用已配置工具，新增工具说明必要性和影响；不在规范落地时夹带全项目格式重写或现有实现的技术栈迁移。

## 指标及数据

指向协议、计时、百分位、分母、缺失值、低置信度和通过阈值的唯一维护位置。区分各负载模式、正常传输结束与业务回答完成。

列明各字段是否允许出现在页面、数据库、日志、下载报告与外发通知中，以及保留期限。产品报告遵循 [REPORTING.md](REPORTING.md) 的既有功能基线，其他项目以实际读取的实现补充，不推定所有模块都能保存正文。未明确允许的敏感内容按现行限制处理。密钥只保存在获授权的安全位置，不能进入报告或测试证据。
