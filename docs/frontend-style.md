# 工作台统一前端

## 视觉契约

首页、公共渠道、准入、定时稳定性、非流式、极限、请求特征诊断和生图八个页面共用 `web/common.css` 的米白背景、深绿强调色、字体、标题比例、表单与焦点样式。模块 CSS 只维护各自布局与状态呈现。新增页面引用公共样式，避免重定义整套根颜色和排版。

定时测试保留标签页、调度状态和弹窗，统一控件和卡片。诊断与生图使用明确的功能标题。非流式保留所有题目、回答、证据和下载。极限测试保留实验室 HTML/JS/基础 CSS，在工作台专有 `relay_lab/web/integration.css` 中将侧栏改为水平模式选择并适配主题；该文件在基础样式之后导入公共样式，按浏览器缓存复用同一资源。实验室独立控制台不加载此工作台适配文件。

保留图表不同序列的颜色语义，尤其在途蓝色与接收中绿色。窄屏可在表格自身区域滚动，页面不能出现整体横向溢出；键盘焦点和环境单选操作必须可见、可用。

## 验证清单

继承 `docs/admission-gpt6.md` v2 的全部十组开发检查、十一组独立检查，以及 `docs/image-quality-testing.md` 的发布容器要求。运行 Python 3.13，Node 24，Playwright 和 Edge。数据、临时文件、venv 和报告均置于仓库外，白名单环境隔离业务配置，全部上游使用本地合成 Mock。

| 检查 | 入口 | 时限 |
| --- | --- | --- |
| 开发十组 | `python -B scripts/verify_admission.py --output <新外置目录>` | 总计 1800 秒，单组按原清单 |
| 独立十一组 | 在干净 detached 提交运行上一入口并追加 `--sha <完整 SHA>` | 总计 3000 秒，包含原有十项 legacy acceptance |
| 八页面交互与主题 | 上述执行器注册的 `node scripts/ui_smoke.cjs` | 600 秒 |
| 诊断容器 | `python -B scripts/diagnosis_container.py --output <新外置目录>` | 外层总计 900 秒 |
| 生图容器 | `python -B scripts/image_quality_container.py --output <新外置目录>` | 外层总计 900 秒 |

浏览器回归沿用公共渠道增改、准入及 GPT-6 协议、三种报告导出、非流式、定时目标、极限 quick Mock、生图确认/生成/取消/下载。追加八页面在 390、900、1440、1920px 的实际主题与页面溢出检查，手机定时计划弹窗，极限推子及固定批次在 390、800、900px 的布局、推子键盘操作与数值同步、环境单选焦点。截图为合成数据，保存在该轮外置目录，交付前人工查看主要页面。

独立审查必须覆盖所有改动、CSS 级联、页面契约和测试本身。无构建配置、依赖、后端业务、协议、数据库或实验室共享代码变更；因为准备发布，仍执行两项容器检查。测试与源码 SHA 对应后才发布标签。发布流水线另核对标签 SHA、两架构镜像与 digest，CI 不代替本地浏览器验收。
