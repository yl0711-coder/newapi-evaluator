# 火山新 Key 一次性验收

工作台入口 `/volcengine-admission/`。选择图片/视频型号和规格，预览每项与合计刊例价，再进行一次性验收。默认 6 款现行型号，另外 5 款为已停止新购的存量兼容型号，计划 2026-11-24 14:00 UTC+8 下线。型号、参数和价格来源由 `catalog.meta()` 列出，核验日期 2026-10-15。

默认 Mock，不访问上游。真实测试固定北京方舟普通按量端点，使用逐次临时 API Key。只读检查不创建生成任务，仅证明任务列表鉴权有效；不能证明 Key 来源、所有模型已开通或图片权限。403 还可能涉及开通/账户限制。Seedance 2.5/2.0 开通另有余额/资源包条件。

每型号只提交一次：图片强制单张；视频固定文生、1:1，不带输入媒体。默认最低规格的六款刊例价估算共 7.1784 元，11 款共 8.07112 元。它们不含免费额度、折扣、资源包，不是供应商扣费上限。报告保留 usage 估价，真实账单始终未核实。选择高分辨率、长时长会改变预览费用；HEVC 的高规格样片可能需本地兼容播放器查看。

创建任务后可切页、刷新、关闭浏览器，后台串行执行。视频拿到 task ID 后查询终态，再保存本地样片；仅返回 ID 不算通过。停止会阻止后续发送和本地查询，已经提交的上游任务可能继续处理/计费。重启后未发送项标记未发送，提交不明项为 unknown，不会重发。补回原 Key 只能继续查询已提交视频；不会重新生成，也不执行上游取消/删除。七天后的上游任务或 24 小时后的签名链接可能无法恢复。

停止时在途请求会先收尾，期间禁止恢复，避免旧查询覆盖恢复状态。指标中的 `elapsed_ms` 为首次发送后的墙钟历时（包含停止/恢复间隔），`submission_elapsed_ms` 为单次提交耗时，`last_query_elapsed_ms`/`query_total_ms` 为查询耗时，单位均为毫秒。单次样本只能描述本次执行，不能证明持续稳定性。媒体容器结构验证及保存成功也不等于已人工看完视频或确认模型身份。

Key、Prompt 和签名链接不落盘。元信息与白名单指标存在 `PLATFORM_DATA_DIR/volcengine-admission/admission.db`；媒体保存在同级 `media/`，通过工作台父鉴权保护的本地编号路由查看/下载，不把上游 URL 交给浏览器。幂等标识只保存摘要，Prompt 仅保存用于恢复期防回显的私有摘要和长度。任务 ID/媒体地址含本次 Key 或 Prompt（包括常见转义）会被拒绝，不把它们持久化或转发到媒体源。

图片重编码 PNG 去元数据。视频仅接收自包含、非分片、单视频轨道的 H.264/H.265 MP4；检查 codec 配置、时间和采样表、媒体偏移与 NAL 长度，清理非播放元数据和 SEI/编码器文本，保持样本偏移。清理后的整个文件还会检查 UTF-8 文本及常见百分号、HTML、Unicode 转义中的本次 Key、Prompt 和当前下载签名 URL 回显；发现残留就拒绝保存，扫描工作量超限为无法判定。该检查不识别画面里的文字或任意隐写编码。空盒、无轨道、无样本或不支持的封装不算通过。此校验不执行实际视频解码，不宣称已经播放或人工看完；不符合支持范围时保留“不完整”结果供诊断，不再生成。

同一运行目录只有一个执行器能取得独占锁；第二实例在数据库初始化/恢复之前失败关闭。最多保留 30 条终态报告、512 MiB/200 个媒体文件。每项生成之前，原子预留其最大媒体容量（图片 24 MiB、视频 128 MiB），串行保存后释放余量；已知容量不足会标记 `not_sent/media_capacity_unavailable`，不发送该项付费 POST。停止/重启释放虚拟预留，恢复已提交视频要重新预留，始终只读查询。外部磁盘变化等仍可能造成提交后的保存失败，此时保留生成状态和 task ID，不重发生成。

页面可查看已用/预留容量，并逐份确认清理终态报告的本地样片。清理保留报告、模型测试状态、usage、task ID，只删除该报告本地媒体并标记 `media_status=removed`；不会取消/删除上游任务，也不会再次下载。清理后需要新测试时重新预览并确认；已提交而未取得样片的视频仍可补原 Key 只读恢复。

HTTP 接口均相对本模块挂载点：

| 方法 | 路径 | 行为 |
| --- | --- | --- |
| GET | `/api/meta` | 静态目录/规格/来源，不初始化服务、数据库或恢复任务 |
| GET | `/api/capacity` | 初始化本地执行器并返回容量对象，取得独占锁；冲突固定脱敏 409 |
| POST | `/api/preview` | `{mode,items:[{model_id,spec}],prompt?}`，返回十分钟有效预览/指纹/预算/容量及警示 |
| POST | `/api/auth` | `{mode,api_key,confirm_read}`，只读任务列表鉴权 |
| POST | `/api/runs` | `{preview_id,fingerprint,idempotency_key,api_key,confirm_live}`，消费预览一次；同幂等标识返回原任务 |
| GET | `/api/runs`、`/api/runs/{id}` | 历史列表与明细 |
| POST | `/api/runs/{id}/stop` | 停止后续发送/本地查询 |
| POST | `/api/runs/{id}/resume` | `{api_key,confirm_read}`，补原 Key，仅 GET 已知视频 |
| GET | `/api/runs/{id}/report` | 脱敏 JSON 报告下载 |
| GET | `/api/runs/{id}/media/{media_id}` | 本地样片；`?download=true` 下载 |
| POST | `/api/runs/{id}/cleanup` | `{confirm_local_delete:true}`，只清理该终态报告的本地样片，返回完整报告 |

`create_app(data_dir=..., transport=..., poll_interval=...)` 用于隔离 Mock 验证；真实传输通过受控 socket 出站，不跟随重定向、不自动重试。查询窗口最多一小时/720 次，失联或窗口耗尽保留已知 ID，用户可选择继续只读查询。聚焦测试命令：`python -B -m unittest tests.test_volcengine_admission`，须设置外置 `EVAL_TEST_ARTIFACT_ROOT`/`TMPDIR`。
