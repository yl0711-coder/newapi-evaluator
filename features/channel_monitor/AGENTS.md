# 渠道自动启停模块

本模块落实用户明确授权的半小时渠道监控和自动启停。遵守仓库根规范，后端 Python/FastAPI，复用公共渠道、完整性传输与现有稳定性调度器，不另起调度服务。

开发及验收仅使用隔离 Mock 或本任务自建无生产凭据的官方rc.26隔离实例，不读取历史计划凭据或修改历史执行器。产品中的管理读取以 `confirm_live=true` 为确认入口；启用持久计划须同时 `confirm_live=true`、`confirm_manage=true`、`confirm_inventory=true`。这只表示操作人在产品中授权所配置的请求、渠道动作及所需飞书只读获取，不授权开发代理调用真实实例。保存连接不发请求，保存映射仅执行已确认的管理读取。

业务规则、版本与边界见 [使用说明](../../docs/newapi-channel-monitor.md)。只修改状态 1/2，必须单渠道审计并回读；未确认写入不可重发或认领所有权。所有停用统一四条保护；先收齐观测判持久熔断，先确认恢复再停用。所有恢复共用本轮完整飞书正向上线成员、确认自有停用、糖果正确和3MT明确匹配门闩；人工锁定、外部接管与未知结果不能冒充已确认失败或合格候补。
